Token 1 of 3 · about 1 minute · account

Create the deploy token

Setup uses this to create the Worker, database, file storage and routes on your Cloudflare account. It's only needed while setting up and updating.

Create the token (prefilled) (opens in a new tab) dash.cloudflare.com ↗
  1. Check what the link filled in

    Name: open-artifacts deploy. Account: yours. Permissions:

    Workers Scripts: EditWorkers KV Storage: EditWorkers R2 Storage: EditD1: EditWorkers Routes: EditDNS: Edit
  2. Continue to summary, then Create Token

    Cloudflare shows the token only once. Copy it, and don't paste it into chat.

  3. Store it yourself

    In the terminal where you'll run setup, run the line below and paste the token when it waits. Nothing is shown:

    read -rs CLOUDFLARE_API_TOKEN && export CLOUDFLARE_API_TOKEN
Token 2 of 3 · about 1 minute · account

Create the access token

Setup uses this to put Cloudflare Access sign-in in front of your instance, so only people you allow can open it.

Create the token (prefilled) (opens in a new tab) dash.cloudflare.com ↗
  1. Check what the link filled in

    Name: open-artifacts access. Account: yours. Permissions:

    Access: Apps and Policies: EditAccess: Organizations: Read
  2. Continue to summary, then Create Token

    Cloudflare shows the token only once. Copy it, and don't paste it into chat.

  3. Store it yourself

    Run the line below. It prompts for the value, so the token never shows on screen or in a transcript:

    gh secret set ACCESS_TOKEN -R you/open-artifacts
Token 3 of 3 · about 1 minute · read-only · optional

Create the analytics token

The dashboard's Usage page reads Cloudflare analytics to show requests and CPU against your plan's limits. This token is read-only and does nothing else.

Create the token (prefilled) (opens in a new tab) dash.cloudflare.com ↗
  1. Check what the link filled in

    Name: open-artifacts analytics. Account: yours. Permissions:

    Account Analytics: Read
  2. Continue to summary, then Create Token

    Cloudflare shows the token only once. Copy it, and don't paste it into chat.

  3. Store it yourself

    Run the line below. It prompts for the value, so the token never shows on screen or in a transcript:

    gh secret set ANALYTICS_TOKEN -R you/open-artifacts
Then: tell your agent "done". It runs setup again and checks each token.
